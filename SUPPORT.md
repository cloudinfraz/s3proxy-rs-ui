# Support

## Questions and usage help

Use [GitHub Discussions](https://github.com/cloudinfraz/s3proxy-rs-ui/discussions)
for setup questions, usage help, and design proposals. Search existing topics
before starting a new one and remove credentials, private endpoints, and
environment-specific operational data.

## Bug reports and feature requests

Use [GitHub Issues](https://github.com/cloudinfraz/s3proxy-rs-ui/issues) for
reproducible bugs and focused feature requests. This community project does not
provide a guaranteed response time or service-level agreement.

The backend API and proxy runtime are maintained in
[`cloudinfraz/s3proxy-rs`](https://github.com/cloudinfraz/s3proxy-rs). Report an
issue there when it does not involve this browser application or UI image.

## Security and conduct

Do not use public support channels for vulnerabilities. Follow
[SECURITY.md](SECURITY.md) for private reporting. Conduct concerns should be
reported as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
